# Jev evaluation — privacy and architecture (experiment only)

**Branch:** `experiment/jev-truth-judge`  
**Status:** Offline benchmark — **not integrated into production**  
**Jev API:** **Disabled** — no TypeSafe early access yet. Code remains for future eval; calls are gated behind `JEV_ENABLED=1`.

## Purpose

Evaluate whether [Jev](https://typesafe.ai/) (TypeSafe System One) can serve as a **bounded advisory layer** for:

1. Question classification
2. Evidence applicability
3. Escalation hints

Jev **advises** the system. It does **not** decide final truth. MeetHint remains responsible for:

- Evidence admission
- `verifyClaim`
- Source authority
- Retrieval policy
- Cite-or-silence

## What data would be sent to Jev (if enabled in eval)

When **`JEV_ENABLED=1`**, `JEV_API_KEY` is set, and `npm run eval:truth-judge -- --judges=deterministic,jev,llm`:

| Field | Sent to Jev? | Notes |
|-------|--------------|-------|
| Question text | Yes (eval fixtures only) | Synthetic questions from `fixtures/evals/truth-judge/` |
| Evidence excerpts | Yes (eval fixtures only) | Truncated to ~800–2000 chars per call |
| Retrieval scores / paths | Yes (metadata) | File paths from synthetic fixtures |
| Customer uploads | **No** | Eval does not read beta or production user data |
| Full repo contents | **No** | Only fixture excerpts |

## API key handling

- **Enable gate:** **`JEV_ENABLED=1`** (required; default off until early access)
- Env var: **`JEV_API_KEY`** (falls back to `TYPESAFE_API_KEY` if set)
- Read in **Node / server-side** code only: `src/lib/truth/jev-client.ts`
- Never imported from browser bundles or client components
- Default eval: `npm run eval:truth-judge` runs **deterministic + LLM** only

## Endpoint

Eval uses the TypeSafe hosted endpoint documented at [typesafe.ai](https://typesafe.ai/):

`POST https://api.typesafe.ai/v1/systemone`

We do **not** assume vendor latency claims — see measured p50/p95/p99 in `docs/experiments/JEV-TRUTH-JUDGE-REPORT.md` after running the benchmark.

## Retention, residency, self-hosting

**Not verified in this repo.** Check TypeSafe / Jev vendor documentation for:

- Data retention after API calls

Do not treat this document as a privacy guarantee.

## Impact on MeetHint local-first positioning

- **Production today:** Files stay on device; normal answer path does not call Jev.
- **This experiment:** Jev is **disabled by default**. When early access is available, opt in with `JEV_ENABLED=1` + `JEV_API_KEY` and `--judges=...,jev`.
- **If ever feature-flagged:** Would require explicit opt-in, minimal excerpt policy, and must remain downstream of `verifyClaim` / cite-or-silence.

## Kill / continue criteria

See `docs/experiments/JEV-TRUTH-JUDGE-REPORT.md` (generated by `npm run eval:truth-judge`).

**Kill** if unsafe continuation exceeds deterministic baseline, false applicability rises materially, latency win is insignificant, privacy tradeoff is unacceptable, or results are unstable.

**Feature-flag candidate only if** unsafe continuation ≤ baseline, accuracy ≥ baseline, p95 latency or cost materially better, and privacy is acceptable.

**Do not merge Jev into production** in this milestone.
